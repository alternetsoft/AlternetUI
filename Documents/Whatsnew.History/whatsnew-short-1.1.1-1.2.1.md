## What's New in 1.1.1-1.2.3

**Main Improvements:**

- Includes 33 new controls and more than 600 improvements and bug fixes.
- Some of the new controls: ToggleSwitch, XScrollBar, XCalendar, SearchTextPicker, FileNamePicker, DrawingResourcePicker, MultilineTextPicker, 
CalendarItemPicker, RepeatPatternPicker, AnimatedSpeedButton, DateTimeIntervalPicker, SplitContentView.
- Enhanced graphics and text rendering with support for underlined and strikeout text, mixed-style text layout improvements, 
vertical text rendering, advanced clipping, transformations, gradients, and drawing paths.
- Adds support for .NET 11.0.
- Updates to wxWidgets 3.3.4 and newer WebView2 and SkiaSharp NuGet packages.
- Loads the legacy PAL library on Linux when required.
- Adds configurable thin scrollbars to scrollable controls.
- Adds a cell selection mode to VirtualListBox.
- Fixes popup window and tooltip behavior on Linux when using Wayland.
- Adds support for the focused state and mouse capture in generic controls.
- Adds the PreferredSizeMode property to controls. This property determines how the preferred size is calculated based on content or available space.
- Expanded SVG support, including SVG rendering in labels and controls.
