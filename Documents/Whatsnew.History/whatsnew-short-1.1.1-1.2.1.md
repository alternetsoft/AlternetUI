## What's New in 1.1.1-1.2.1

**Main Improvements:**

- Includes 30 new controls and more than 600 improvements and fixes.
- New controls include ToggleSwitch, XScrollBar, XCalendar, SearchTextPicker, FileNamePicker, DrawingResourcePicker, MultilineTextPicker, CalendarItemPicker, RepeatPatternPicker, and SplittedContentView.
- Adds .NET 11.0 support.
- Updates to wxWidgets 3.3.4 and newer WebView2 and SkiaSharp NuGet packages.
- Loads the legacy PAL library when required on Linux.
- Adds configurable thin scrollbars to scrollable user controls.
- Adds a cell selection mode to VirtualListBox.
- Fixes popup window and tooltip behavior on Linux with Wayland.
- Adds support for the focused state and mouse capture to generic controls.
- Adds the PreferredSizeMode property to controls. This property controls how the preferred size is computed based on content or available space.
